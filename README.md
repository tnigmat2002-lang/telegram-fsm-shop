A Telegram bot for small businesses to collect orders step-by-step using aiogram 3 (FSM) and SQLite.
This is a portfolio project demonstrating an asynchronous Telegram bot for local businesses.
Features:

Step-by-step order collection using Finite State Machine (FSM).

Saving incoming orders to a local SQLite database.

Hidden admin panel for managing requests.
Stack: Python, aiogram 3.x, SQLite.
